## Lab Descriptions

### Lab 1: Boolean Logic & Multiplexing

Implemented fundamental Boolean logic gates and explored how logic gates can be combined to build digital circuits. Studied Boolean expressions and truth tables to understand the behavior of different logic operations.

### Lab 2: 4x1 and 8x1 Multiplexing

Implemented 4-to-1 and 8-to-1 multiplexers to select one input from multiple input signals using select lines. Explored how multiplexers help control and route data in digital systems.

### Lab 3: Half Adder, Full Adder & Add16

Designed arithmetic circuits using HDL, including the Half Adder, Full Adder, and 16-bit adder (Add16). Learned how binary addition and carry propagation work in digital circuits.

### Lab 4: ALU Implementation

Implemented the Arithmetic Logic Unit (ALU), which performs arithmetic and logical operations based on control inputs. Explored how an ALU processes data and generates output and status flags.

### Lab 5: Bit, Register, RAM8K, RAM64K & PC

Worked with sequential logic and memory-related components, including the Bit, Register, RAM chips, and Program Counter (PC). Explored data storage, clock-controlled updates, memory organization, and address-based data access.
